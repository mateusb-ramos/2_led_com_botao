## Enunciado: Vamos controlar LEDs com um botão!

O projeto vai utilizar um botão como entrada para controlar dois LEDs como saída. Ao pressionar o botão, o Arduino altera o estado dos LEDs, permitindo controlar os LEDs verde e vermelho de acordo com a programação.

- O Arduino lê o estado do botão pelo **pino 7**
- Controla o LED verde pelo **pino 12**
- Controla o LED vermelho pelo **pino 9**

## Materiais necessários

| 1 | LED vermelho difuso de 5 mm |
